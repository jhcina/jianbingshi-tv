# 把自己的照片放进电视

## 电视直接导入

设置 → 背景 → 我的壁纸 → 导入照片，选择 U 盘或本机图片。此功能依赖系统 `ACTION_OPEN_DOCUMENT` 文件选择器；部分电视固件没有提供，出现提示时使用下面的电脑方法。

每次选一张，最多 30 张。导入只复制选择的图片，不申请整个相册的读取权限。处理在本地完成，导出 1920×1080 的电视副本与缩略图，去除原始 EXIF，按 EXIF 方向摆正。竖幅和其他比例采用深色留边，保留完整画面，不拉伸或重绘人物。原图不动；导入成功后仍需本人选择应用，当前壁纸不自动改变。

仅存本机表示不随源码、APK 分发，也没有照片上传服务；不表示加密或防止拿到遥控器的人打开图库。卸载应用通常会删除这组应用专属文件，原片须自行保留。

## 电脑导入（无需重新打包）

电脑准备 Python、Pillow 和 Android Platform Tools，按电视提示启用调试并亲自确认授权。先安装并打开本 App。用 `adb devices` 核对目标，不自动选第一台。

```sh
python -m pip install 'Pillow>=11,<13'
python scripts/import_photos.py --serial <电视设备标识> /path/to/photo1.jpg /path/to/photo2.jpg
```

可加 `--adb /path/to/adb`、`--server-port 5037`；没有修改服务器端口时不用填。工具在仓库外的临时目录处理图片，保留已有图库清单，先传图片，最后替换清单并读回验证；不更改 Home、系统应用或当前壁纸。请在电视端没有同时导入时运行。重新打开桌面，在“我的壁纸”选择照片。

公开包为 `io.github.jhcina.yitv`。此前私人试用包如仍需保留，显式指定 `--package io.github.op7418.guizangtv.yi`；两个包的图库分离，互不自动复制。请不要把个人目录、图库清单或实机诊断记录放进仓库。

## 看照片

从设置进入“看照片”，或在首页按菜单键。提示 4 秒后消失，左右在当前图库换图，确定或返回回桌面。自动轮播使用已有间隔；默认图库始终只切换默认照片，“我的壁纸”始终只切换私人照片。音量键交给系统处理。

如果背景为纯色，先切回照片背景。这不是屏保服务，不改变电视息屏和省电策略。电视本身的画面模式、局部调光和锐化仍需按观看环境调整；图片尺寸不等于真实细节增加。
