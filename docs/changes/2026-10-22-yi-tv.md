# 煎饼使 TV 0.5.0-yi.preview.1

基线：归藏 main `312c01119a327f402e68818670a6542f1e643e56`，完整上游历史保留。此分支不是上游官方发布。

## 行为变化

- 公开包名 `io.github.jhcina.yitv`，独立发布签名；私人试用包可通过显式构建属性 `yiApplicationId` 保留。两者不自动迁移设置和图库。
- 新用户首页只预选本机可启动的应用，不要求安装作者家里的四个 App；已有用户排序与外观不重置。
- 新增“看照片”模式：设置或菜单键进入，4 秒后隐藏提示，左右切换当前图库，确定/返回回桌面。音量键交给系统，未主动改变待机策略。
- 新增通过系统文件选择器单张导入照片；处理在后台，EXIF 方向识别采用 AndroidX ExifInterface 1.4.2，限制尺寸与图库容量，原子保存清单。图片副本不带原 EXIF；竖幅完整留边，不重绘人脸。明确识别 MFTR0 的占位文件选择器并提示电脑导入。
- 新增电脑导入脚本，明确指定设备，保留原片和已有清单，读回核验，不改 Home 或系统应用。
- 默认/私人图库分开存放和轮播；私有图库在 scoped external files，而非 APK assets。构建前核对允许文件与 SHA-256，拒绝清单外位图。
- 黄色圆角纸片、左上光源与右下阴影，保留原有毛玻璃选项；App 图标与横幅重新绘制。
- 新增 MFTR0/Android 14/OS3.0.101.0.UFTMATV 的局部配置与可选 Home 窗口返回；HDMI 1/2/3 参数 23/24/25 仅对该实测配置启用，其他品牌不继承。
- 三张本人航拍署名煎饼使，单独注明随项目分发权限；五张 Unsplash 照片通知保留。人物照片、个人日志、密钥与 AI 室内重建图不公开。

源代码 Release 单元测试 37 项通过，照片脚本测试 5 项通过；Release lint 无错误，保留既有警告。公开签名包在 MFTR0 安装、启动，并完成电脑导入与覆盖安装；实机详细结果见 YI-COMPATIBILITY.md。Android 文件选择器完整导入流程仍需在有真正选择器的设备上验证。
