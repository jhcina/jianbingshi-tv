# 搭配哪些应用

煎饼使TV 是桌面。应用先从原作者或官方渠道安装，能够单独打开后，再到“设置 → 常用应用”添加。安装软件不自动获得其中节目的观看或转播授权。

## 先按需要选，避免装一堆重复软件

| 用途 | 建议 | 下载与配置 |
| --- | --- | --- |
| 哔哩哔哩、腾讯视频等已有服务 | 沿用自己已使用的电视客户端，不重复安装同类软件 | 电视应用商店或服务方官方渠道；账号与订阅由用户管理 |
| 极空间里的家庭影音 | 已经使用极空间的家庭，优先保留原客户端 | 极空间官方客户端；NAS 与账号自行配置 |
| 短剧 | 有需求时自行选择红果电视端 | [原版来源与三步指引](APP-INTEGRATION.md)，独立第三方客户端，不代表红果官方 |
| 本地、U 盘和网络媒体 | 简单播放优先考虑 VLC；需要媒体库再考虑 Kodi，先选一个 | [VLC 官方 Android 页面](https://www.videolan.org/vlc/download-android.html) / [Kodi 官方下载](https://kodi.tv/download/)，不用陌生镜像的修改包 |
| 自建 Jellyfin 影音库 | 已经有 Jellyfin 服务器再安装 Android TV 客户端 | [Jellyfin 官方客户端](https://jellyfin.org/clients/)；没有服务器无需先装 |
| 电视直播 | 先用电视运营商、频道方在当地提供的服务；自有授权播放列表再考虑一个 IPTV 播放器 | 不附频道源，不承诺翡翠台、明珠台、日本台或其他海外频道可收看 |

以上是按用途筛选的安装建议，不是这些软件已经预装、逐一通过本项目实机验收或允许我们重新打包的声明。

## mytv-android：先辨认是哪一个项目

核对日期：2026-10-25。同名不代表同一应用：

- [yaoxieyoulei/mytv-android](https://github.com/yaoxieyoulei/mytv-android) 是原生 Android 播放器，支持自定义订阅源；仓库已归档。README 提到默认订阅源需 IPv6，不应据此承诺所有网络即装即看。
- [mytv-android/mytv-android](https://github.com/mytv-android/mytv-android) 是另一维护分支，README 已说明不再公开源码。仓库中的 LICENSE_ORIGIN 和 LICENSE_PART1 分别对应原项目及引用代码，不能仅靠它们推定当前整个发行 APK 可供我们打包。

朋友已用的具体仓库、版本、签名和源尚未取得，因此先作为个人电视的一个候选，不宣称它是当前最优。确认本人使用的来源后，再与其他候选比较遥控器操作、换台、失败提示和低配置性能；同用途只保留一个。

**播放器像收音机，频道地址像调到的电台。能调出来，不等于我们获得了把它转送给所有人的许可。**我们不分发朋友的频道清单、订阅凭证或地区绕过配置。频道在不同地区、设备、账号下的可用性由服务方决定；例如 [myTV SUPER 官方 FAQ](https://promo.mytvsuper.com/tc/faq_webview) 明确服务适用于香港或澳门，取决于订购计划。它与上述同名 GitHub 播放器不是同一产品。

## 如何看待 TVAPP 收集站

[youhunwl/TVAPP](https://github.com/youhunwl/TVAPP) 是第三方 APK 与资源收集目录，不是全部软件的原作者或授权证明。其 README 混有原版、修改版、会员解锁版、内置源和外部下载链接；“仅学习”“侵权删除”不能代替再分发许可。

- 有实际价值的方向：本地播放器、媒体库和文件传输。本文优先给原作者来源，不复制收集站的 APK。
- Kodi 值得有媒体库需求的人考虑；目录里链接到的 alpha/snapshot 不作为我们面向新手的默认推荐，优先官方当前稳定下载。
- 我的电视、酷9、HTV、观屿等与 mytv-android 都有 IPTV 播放用途重叠，功能、内置内容和许可不同。没有同机实测与授权核对前，不按频道数量排名，也不同时装一批。
- 不推荐把“解锁会员”“内置海量未知源”包纳入本项目的公开附件或引导安装方案。

当前公开方案：**只分发我们的桌面；第三方应用提供原作者链接和用户选择的安装说明。**

## 将来能否做可选整合包

可以逐项评估独立 APK 的合集，但需明确对应版本的分发许可、版权通知、依赖和更新责任。GPL 软件还需按适用条款提供对应源码等材料；把多个独立应用放进 ZIP，不自动让桌面代码变成 GPL，也不免除各软件自身的义务。VLC、Kodi 等有明确开源许可，是比未知修改包更适合进一步核对的候选；本版不包含它们的 APK。

频道播放权、地区和账号限制另行核对。只有软件许可不足以批准附带频道源。依据：[著作权法](https://www.nsfc.gov.cn/p1/2871/2872/69475.html)第十条及第四十七条、[VLC 源码许可说明](https://github.com/videolan/vlc-android#license)、[Kodi 内容说明](https://kodi.tv/about/)。
