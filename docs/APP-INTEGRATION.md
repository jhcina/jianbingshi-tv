# 红果电视端怎么一起用

结论先说：**可以把自己安装的红果电视端加入本桌面的常用栏；本次不做红果 APK 的预装或整合分发。**这不会影响你已在自己电视上安装的原版。煎饼使TV是桌面，红果是另一个 App，双方独立升级。

## 三步使用

1. 打开原维护者渠道有数的 [电视指南](https://github.com/waligoraamodio288-rgb/hongguo-desktop-releases/blob/main/TV.md)，进入 [原版 0.5.9 发行页](https://github.com/waligoraamodio288-rgb/hongguo-desktop-releases/releases/tag/tv-v0.5.9)。这里记录 2026-10-25 的核对版本，后续以原电视指南为准；不要误下 Windows / Mac 包。
2. 按电视系统支持的架构选择 ARM32（armeabi-v7a）或 ARM64（arm64-v8a），不按芯片广告位数判断。按系统正常提示安装；已有同签名原版可覆盖更新，勿通过卸载解决签名冲突。
3. 重新打开煎饼使TV → 设置 → 常用应用，把“红果电视端”加入常用栏。添加的是你本机的启动入口；本桌面不复制观看记录、剧集和会员。没有出现时先确认该 App 能从系统应用列表单独打开。

本分支 MFTR0 样本使用 0.5.9 ARM32（cn.hongguo.tv，versionCode 19）。SHA-256：`c8311b116f7ebce0d56291c76ef2b7153011378faa4a5a3c708774a881577051`；签名证书 SHA-256：`c996ebad47f3f9881abbba3947a5a3374800cfe20b500c3a5f554569dc71a5ac`。同一失败样本更新后第二集出画面并观察到继续至第四、第五集；不保证所有剧目、网络和电视。
