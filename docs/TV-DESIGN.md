# 当前电视视觉规范（preview.4 源码）

目标是远距离看清入口、识别焦点，并让照片有安静的展示空间。采用黄黑主体与克制的材质，不为图标叠加装饰底板。

- 深色与照片主题：图标为黄色，文字为暖白；纯浅主题为深色图标、文字。照片使用整体遮罩，尚未实现按照片局部亮度自动反色。
- 聚焦工具使用暖黄表面与深色字形；沿用已有聚焦/按压动效，不做装饰性常驻动画。静态截图不代表动效或音画验收。
- 纵向应用图标共用 52dp 对齐槽，按主体观感校准不同 SVG；65dp 行保持六项可见。文字淡化不再同时淡化图标。
- 右侧图文工具共用左起点；纯图标工具靠右，焦点名称在图标左侧出现，保持图标位置。纯文字行为、横向 Dock 与方向键连接保持原有路径。
- 横向 Dock 少量居中、较多随焦点滚动；工具向下回到当前应用。关闭系统动画时直接定位。
- 默认主体优先使用可着色向量，原始来源及版权保留；未知 App 可回退为本机图标或统一工具符号。HDMI/投屏为原创主体，工具多数来自 Phosphor，品牌主体部分来自 Simple Icons。

默认位图素材按 catalog 与摘要校验；私人图片只在运行时。曾测试的陶瓷图标不是当前默认视觉，见 [历史记录](TV-DESIGN-HISTORY.md)。

阶段验收：深、浅、照片背景与图文模式在 MFTR0 已查看。2026-10-25 纯图标右对齐修复已同签名覆盖安装，在 MFTR0 查看纯图标、聚焦名称与恢复图文模式，Home 三轮通过，19 个图库文件逐项摘要不变。截图见 [说明](screenshots/README.md)。
