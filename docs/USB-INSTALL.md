# U 盘离线安装

下载页的 `jianbingshi-tv-0.5.0-preview.4-usb.zip` 只包含煎饼使TV安装包、文字教程和校验文件。没有第三方 APK、频道源、电脑驱动或自动执行脚本。

## 准备与安装

1. 在手机或电脑下载 ZIP 并解压。把里面以 `.apk` 结尾的文件复制到 U 盘容易找到的位置，不要只复制 ZIP。
2. 电视开机后插入 U 盘，在电视自带“文件管理 / 媒体中心 / U 盘”入口查找文件。菜单名称以该电视为准。
3. 用遥控器打开 APK，按系统提示允许本次对应安装来源并确认安装。不要关闭其他系统防护。
4. 安装完成后，在电视应用列表打开“煎饼使TV”。首次使用先设置常用应用和壁纸，无需先修改 Home 或启用实验恢复。

从复制 APK 到确认安装不要求联网访问 GitHub；之后打开在线应用、天气等仍取决于网络。内置照片和基础桌面可离线使用。

本教程是通用方法，不是各品牌 U 盘实机验收。电视若不显示 APK、禁止第三方安装或没有文件管理入口，参照厂商说明；能读取照片不一定能安装 APK。不要反复改后缀或套用其他机型的刷机/禁用系统桌面教程。

## 为什么不能插上就全部自动完成

普通 Android App 的首次安装通常要经系统安装器确认；未知来源、主页、辅助功能和通知监听等属于不同授权。本项目没有厂商系统签名、设备管理权限或 root，不提供绕过确认的方法。参见 [Android PackageInstaller](https://developer.android.com/reference/android/content/pm/PackageInstaller.SessionParams#setRequireUserAction(int))。

当前做到的是“解压 → 复制 APK → 电视确认安装 → 打开”。尚未实现手机扫码传包、安装后一页式引导或第三方应用一键安装，不能据此宣传插盘全自动。电视不支持 U 盘安装时，见 [其他安装方法](GETTING-STARTED.md)。
