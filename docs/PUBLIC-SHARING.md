# 公开分享与版本定位

更新日期：2026-10-25。

## 现在可以分享什么

可分享已经发布的桌面和实际界面，表述为“基于归藏，用 AI 协助把自家电视首页做成常用应用＋个人照片桌面”。推荐链接仓库首页，让读者先看截图、用途和安装方法，再选择下载。不要称为重写电视系统、全品牌开机接管或免费收看全部频道。

人物照片、家庭通知、账号、二维码、设备地址和序列号不放宣传图；目前 README 的公开截图可作为素材来源，保留相应摄影作者说明。分享项目不等于可以独立销售壁纸。

## 是否直接变成正式版

当前 preview.4 已可公开体验，核心桌面与照片路径已有验证。正式版不需要覆盖所有电视，但须对承诺的核心用途形成可重复的安装、使用、更新和恢复闭环。

本轮不因宣传移除 preview，也不移动旧标签或给相同 APK 改名冒充新版本。建议首个正式版采用 **0.5.0**，无需跳到 1.0；升级 versionCode，签名与公开包名保持一致。正式版的启动适配仍可标实验且默认关闭。

发布 0.5.0 前优先完成：

1. 在承诺机型用公开签名包走一遍新安装、配置、进出常用应用及覆盖更新。电脑构建通过不能替代这条路径。
2. 照片主流程补齐或明确缩小承诺：当前没有单张删除/导出界面，且部分电视只能用电脑导入。不能宣传“任何家庭免电脑管理照片”。
3. 普通 App 使用路径在重启后能重新打开、设置/图库保留；Home/开机实验单独验收。未验证持久接管不阻止收窄范围的正式版，但不能把它写成默认卖点。

后续按 [发布准备](RELEASE-READINESS.md) 核对；本轮仅改介绍与安装材料，不更改 APK 的身份和版本状态。

## 能否在别人的仓库放链接

- 自己的 GitHub 主页及相关自有项目，可以加入相关项目链接，保留清楚描述。
- 别人的仓库不能直接修改。若对方明确接受案例、周边工具或相关项目，可以按贡献指南提交相关条目，请维护者决定；应贡献有用信息，不把 Issue 当广告位。
- 不群发评论、不批量开推广 Issue、不假装官方合作。本轮没有到其他仓库发言或提交推广。
