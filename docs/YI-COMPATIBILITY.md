Home 自动返回是可选辅助功能，默认关闭，仅接收小米原桌面窗口变化；必须由设备本人开启。主动打开小米原桌面时暂停跳转，再次打开本桌面后恢复。关闭方式：设置 → 电视与启动 → 关闭 Home 自动返回；也可从系统辅助功能停用“煎饼使TV 主页返回”。只删除自己的启用项，不清空其他辅助功能。

不启用开机与 Home 设置时，作为普通 App 退出即可。卸载前先备份私人原图，并停用自己启用的 Home/开机配置。保留系统原桌面，不执行系统应用禁用或清理脚本。开机配置说明见 BOOT-START.md，但其中上游包名须换为本 fork 的实际包名；不确定时不要设置。

## 0.5.0-preview.2 首页返回修复验收

2026-10-23：读取到旧版暂停标记为 true；旧版首页 Back 会打开原桌面并写入该标记。新版首页 Back 留在首页，明确选择原桌面才暂停，重新打开定制桌面恢复。

同机连续三轮“首页 Back → 文件管理 → Home”自动设备检查通过。之后设备本人用真实遥控器从常用 App 按 Home，反馈“会，已经正常返回”。这是当前会话的真实 Home 验收，不替代待机或重启持续性测试。音量保留系统控件；连续长按仍未取得明确验收。

可重复检查（不启用权限、不改默认桌面）：

```sh
python scripts/check_home.py --serial <电视设备标识>
```

该脚本仅对已测 MFTR0 固件、已由本人启用服务的设备执行；它会切换桌面/文件管理，不用于其他品牌兼容性宣称。
