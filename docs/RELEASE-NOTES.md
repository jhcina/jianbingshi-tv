# 煎饼使TV 0.5.0-preview.2

基于归藏 guizang-tv 的独立 fork，公开包名仍为 `io.github.jhcina.yitv`，保留上一版签名，可覆盖更新。此为桌面 App，不刷写电视系统。

## 本次修复

- 首页按返回键不再退出到小米桌面并暂停 Home 返回；首页返回只提示已在首页。设置中明确打开“小米原桌面”才暂停，并提示重新打开本桌面恢复。
- 手动重开桌面时清除暂停标记，避免留在暂停状态。
- 对外统一名称“煎饼使TV”，GitHub 仓库名 `jianbingshi-tv`，新的下载文件使用该名称。内部包名、签名及原有设置不因品牌变更迁移。

本机验证：首页 Back→文件管理→Home 连续三轮设备检查通过，之后本人真实遥控器 Home 反馈正常。该结果不证明待机/重启后持续有效。

## 已有能力

本机照片导入、默认/私人图库分开存储与轮播、保留完整竖幅的留边处理、看照片模式、黄色纸片焦点，以及指定 MFTR0 固件适配。基础设置、Dock、预览、天气和 Codex 来自归藏，保留来源。

## 试用边界

Home 返回默认关闭，只在已适配设备由本人开启；不读取屏幕内容、不拦截音量键。MFTR0 待机后检查曾发现辅助功能列表为空，清空原因未确定，仍不承诺待机或重启后保持。其他品牌未实测。完整重启、真实遥控器长按音量、HDMI 外接音画、小爱及投屏播放仍需分别验证。
