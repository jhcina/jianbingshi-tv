# 煎饼使 TV 0.5.0-yi.preview.1

这是基于 [归藏 guizang-tv](https://github.com/op7418/guizang-tv) 的独立 fork 预览版，面向想把自己照片放进客厅电视的用户。不是刷机固件，也不代表上游官方发布。

- 新增“看照片”：收起首页文字与时钟，左右换图，确定/返回回桌面。
- 新增本机照片导入。竖幅完整留边、去除 EXIF；公开与私人图库分开存储和轮播。电视无系统文件选择器时，提供电脑导入脚本，无需重新编译。
- 黄色圆角纸片焦点、左上光源与阴影、新 App 图标；保留原来的列表、Dock、毛玻璃和设置。
- 初次首页根据本机应用生成，已有排序和外观不重置。
- 加入 Xiaomi MiTV-MFTR0 指定固件配置与可选 Home 返回，其他品牌不套用小米参数。

公开包名 `io.github.jhcina.yitv`，与归藏原版、此前私人试用包并存；不会自动迁移其设置和照片。请使用同一发布签名覆盖升级，不要为解决签名冲突直接卸载有个人照片的版本。

已验证：Release 构建与签名、37 项 Java 单元测试、5 项 Python 照片流程测试、lint 0 错误；MFTR0 实机安装、覆盖升级、看照片界面、电脑导入读回及图库应用。已有 23 个 lint 警告，未声称全部消除。

未验证：完整重启、真实遥控器长按音量、外接 HDMI 音画、小爱/投屏播放，以及其他电视。Android 系统选择器完整导入流程需在有真正选择器的设备验证；本次 MFTR0 只有占位选择器，已给出电脑导入提示。

代码 MIT，保留全部来源通知。默认八张照片中三张航拍署名煎饼使、五张沿用 Unsplash 许可；照片不适用代码 MIT。人物照片、个人日志、签名密钥、AI 重建室内图不包含在公开源码或 APK 中。

使用前请看 [兼容与恢复](https://github.com/jhcina/yi-tv/blob/main/docs/YI-COMPATIBILITY.md) 和 [照片导入](https://github.com/jhcina/yi-tv/blob/main/docs/PHOTOS.md)。Home 自动返回默认关闭，启用须设备本人授权；基础使用不需要辅助功能。
