记录：2026-10-23。推荐下载 preview.3，本轮视觉与设置升级仍属预览版，不是稳定版。不能通过去掉 preview 字样完成验收。

## 正式版承诺应当收窄

首个稳定版建议只承诺“Android 电视上的常用应用与本机照片桌面”，标明实际测试设备。Home 自动返回、开机、厂商 HDMI、天气和 Codex 作为独立可选能力，不将它们的实验状态写成全品牌系统替换能力。无需等所有电视都支持才能发布，但承诺范围内的体验必须完整。

已知 preview.2 基线：37 项 Java 测试、5 项 Python 测试；lint 0 错误、23 个既有警告。此前运行结果不是 preview.3 的验收。仅编译成功、截图好看或脚本点击成功都不等于真实遥控器验收。

## 为什么用户会选择这个分支

极简、壁纸、Dock、设置和应用排序都是归藏的基础贡献，不作为独创卖点。黄色按钮是识别资产，单独换色不是充分安装理由。

本分支已经形成的用途差异：无需重编译就能导入私人照片；公开图库与个人图库分别轮播；看照片可暂时收起桌面文字；竖幅保留完整画面；首次入口依据安装应用发现。适合想让电视显示自己拍摄内容、只保留几个常用入口的家庭。现在受限于导入门槛和图库管理缺口，尚未证明适合不愿折腾的全部家庭用户。

下一轮优先放大“自己的照片真的能长期用”：先补删除/撤销、容量说明、备份恢复，再研究免电脑的本地手机导入。后者需要设计明确授权、短时配对与退出关闭，未实现前不宣传。其次优化远距离可读性、焦点一致性和家人无需解释的返回路径。只有这些主流程稳定后，再考虑更复杂动效和附加功能。

不把 UI 改装说成重写电视系统，不把对归藏的衍生说成从零独创，不为追求差异堆天气、AI 对话和系统权限。

## 版本保留策略

对外只突出一个已验证下载入口；过时且被修复版替代的自有预览发行可撤下，先在本机备份元数据、源码、APK 和校验值。保留 Git 提交和标签，保留上游来源历史。稳定版具备发布条件后再单独发布并设为最新稳定版，不覆盖旧 APK 文件，不移动已有标签，不复用版本号。
