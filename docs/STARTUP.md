# 一次设置启动方式

适用状态：preview.3 可按本文手动设置；preview.4 的首次启动向导和配置工具仍是本地候选，尚未实机验收。不能承诺装一个 APK 就自动成为所有电视的默认桌面。

## 三件事分别确认

- **默认桌面**：由系统选择首页应用。有系统选择器时，需要本人确认；某些厂商不开放或会覆盖这个选择。
- **开机自动进入**：完整重启后进入指定应用。小米部分固件有单独启动目标，不等于默认桌面。
- **遥控器关屏再打开**：可能只是待机唤醒，不会产生一次新的完整开机。需要另做验收。

第一次使用先试普通应用入口。候选向导会读取实际配置，能打开系统默认桌面选择器时交给系统确认；不通过后台反复写权限来强迫保持默认。

## 已适配小米：电脑配置一次

当前脚本只允许 MFTR0 / OS3.0.101.0.UFTMATV，和上游已记录的 MTSU0 / OS3.0.119.0.UTSMATV。其他品牌或新固件会拒绝写入，先走系统默认桌面选择，等待实测适配。

1. 安装并打开对应版本。公开版包名 `io.github.jhcina.yitv`；此前私人试用包为 `io.github.op7418.guizangtv.yi`，二者不是同一个应用，也不自动迁移照片。
2. 设置 → 电视与启动 → 开机自动进入，确认开启。仅开这个开关还不够，系统目标也要配置。
3. 电脑准备 Python 3 和 Android Platform Tools，在电视确认调试授权。用 `adb devices` 核对自己的设备。
4. 在候选源码目录执行，只检查不会改设置：

```text
python scripts/setup_startup.py --serial <电视IP:端口> --check
```

完成一次配置：

```text
python scripts/setup_startup.py --serial <电视IP:端口> --apply --backup startup-backup.json
```

脚本会先备份原值，再把开机目标设为指定包，并关闭开机信号源优先；写后读回。已有别的启动目标时会拒绝覆盖，需看清原设置后再决定是否增加 `--replace`。不会启动应用、重启、禁用系统桌面、改辅助功能或清空任何数据。

私人试用包必须显式增加 `--package io.github.op7418.guizangtv.yi`。ADB 改过服务器端口时显式加 `--server-port`，可用 `--adb` 指定工具路径。

5. 在电视空闲时完整重启，观察是否自行进入，再测真实遥控器主页键；另测关屏/唤醒。不要用电脑手动打开应用来替代自动启动验收。重启可能关闭网络调试，验证自动进入本身不依赖电脑在线。

保留备份文件，只在本机保存。若要恢复：

```text
python scripts/setup_startup.py --serial <电视IP:端口> --restore startup-backup.json
```

恢复前会核对机型、固件、包名与当前目标，避免覆盖后来改过的选择。应用内自动进入开关另需本人关闭；卸载前先解除指向它的启动配置并保留原片。

## 两个同名图标

先到电视系统应用管理核对安装包；原生桌面可能显示不同版本，或者同一包的多个启动/缓存入口。图标数量不能直接证明安装了两份。不要凭图标长按卸载，否则可能连同正在使用的照片和偏好一起删除。候选向导会提示另一份公开/私人版本是否存在；尚不自动删除任一版本或清空厂商桌面。
