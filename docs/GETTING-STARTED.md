# 第一次使用煎饼使TV

目前只有预览版，尚无正式稳定版。它是 Android 电视上的桌面 App，不是电视固件。优先先作为普通应用试用。

## 1. 下载哪个文件

[下载 0.5.0-preview.4 安装包（预览版 APK）](https://github.com/jhcina/jianbingshi-tv/releases/download/v0.5.0-preview.4/jianbingshi-tv-0.5.0-preview.4.apk)。这是当前推荐的签名预览包；普通桌面、照片与会话内 Home 已做阶段检查，不代表完整开机/待机或跨品牌验收。

文件结尾必须是 `.apk`。`source.zip`、GitHub 的 Source code 是给开发者的源码，不能在电视上安装。没有“最新版正式版”下载按钮，是因为目前还没有稳定版。

要求 Android 8.0 及以上；小米 S Pro 75 的 MFTR0 指定固件有本分支实测。创维、TCL 等暂未实测。版本号满足不等于所有功能兼容。

## 2. 装到电视

如果电视支持从 U 盘安装：把 APK 复制到 U 盘，在电视文件管理中打开它，按系统提示允许对应安装来源并安装。不同品牌可能限制 U 盘安装；找不到安装入口时，不要照抄其他品牌的系统修改步骤。

已开启网络调试的用户可用电脑安装：下载 Google 官方 [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools)，解压后在该目录打开终端。电视和电脑连接同一局域网，在电视设置里查看 IP 并开启网络调试。下面的 IP 与文件路径需要替换成自己的值：

```text
adb connect <电视IP>:5555
adb devices
adb -s <电视IP>:5555 install -r <下载的APK完整路径>
```

路径含空格时加双引号。电视弹出调试授权时由本人确认；设备状态为 `device` 才继续。并非所有固件都使用 5555，若系统显示其他端口或配对码，请按该固件说明配对，不要反复猜端口。安装完成后从应用列表打开“煎饼使TV”。不要求刷机或删除原桌面。

## 3. 第一次打开做什么

- 设置 → 常用应用：添加、排序、隐藏常用应用。隐藏不会卸载应用。
- 设置 → 照片与背景 → 默认壁纸：选择公开风景照片。
- 设置 → 照片与背景 → 我的壁纸 → 导入照片：需要系统文件选择器。若提示缺少选择器，见 [电脑导入方法](PHOTOS.md)。S Pro 75 实测需要电脑方法，目前还不是手机一键导入。
- 设置 → 看照片：收起首页文字，左右换图，确定或返回退出。

自己的照片只复制到应用专属图库，不上传，也不随公开 APK 分发。当前最多 30 张，导入副本为 1920×1080，原片保留；这不等于 4K 相册。尚无图库删除与导出界面，务必保留原图，不要通过卸载来处理个别照片。

## 4. Home 和开机：可选实验

先用普通 App 入口。Home 自动返回默认关闭，仅适配的固件且本人在系统辅助功能中启用后才工作；目前没有待机/重启持久性保证。其他品牌不套用小米参数。开机自动进入不是安装必需步骤，本指南不要求修改启动配置。

想恢复时先在系统辅助功能停用“煎饼使TV 主页返回”，关闭自己启用的开机入口，再从原桌面使用电视。系统设置页面由电视厂商提供，与本 App 的外观不同。

## 5. 更新与反馈

同一公开签名的新版通常覆盖安装并保留数据。归藏原版、此前私人试用包、自行构建 Debug 包可能属于不同应用或签名，不自动迁移数据；签名冲突不要直接卸载有照片的版本。

遇到问题请在 [Issues](https://github.com/jhcina/jianbingshi-tv/issues) 写清机型、固件、安装版本、操作步骤和实际结果。截图先隐去人物、账号、网络地址和二维码。详见 [实测范围与恢复](YI-COMPATIBILITY.md)。
